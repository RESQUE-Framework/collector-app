Pack validator

Checks RESQUE pack files and this app's configuration with the same rules as Pack validation in the collector. Everything runs in your browser; no file is uploaded. Each result names the rule, the pack file and line, and how to fix it. See the rule list in documentation/RESQUE-Pack-Guide.md ("Validator rules"). On the command line, the same checks run with node scripts/validate-packs.cjs.

Only errors in stable packs of active output types block the collector. Problems in inactive output types and in alpha or beta packs are listed as not blocking. A production app should have no errors and no warnings among its current problems.

1. This app's configuration

The packs selected in config/config.yaml (or config/config-default.yaml) after include/exclude, presets and score categories - what applicants will see.

2. All packs of this app

Every configured pack and every pack in the preview catalog (packs/info.json), each on its own. Publication expansion packs are checked together with the publication core. Archived packs are only checked for valid JSON.

3. A pack file of your own

For a new or changed pack, e.g. an expansion pack you are developing. The file is read locally.
